# DSA Notes

This directory is for explanations that outlive a single solution: patterns, trade-offs,
proof sketches, and reusable Java techniques. Problem-specific notes remain beside their
solutions in `leetcode/src/main/java/.../problemXXX/README.md`.

## Start here

- [Problem-solving workflow](problem-solving.md) — a repeatable way to move from prompt to a verified solution.
- [Solution status](solution-status.md) — inventory of the exercises currently in this repository.

## Suggested topic structure

Add one Markdown file per topic, for example:

```text
Docs/
├── arrays-and-hashing.md
├── two-pointers.md
├── binary-search.md
├── linked-lists.md
├── trees-and-graphs.md
└── dynamic-programming.md
```

For each topic, capture the trigger words, invariant, Java template, complexity, common
mistakes, and links to representative solutions in this repository.
